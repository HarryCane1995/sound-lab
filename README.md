# SOUND LAB 0.6

Локальная браузерная лаборатория звукового синтеза: меняйте параметры, слушайте результат и сравнивайте реальную форму сигнала с его спектром. Приложение рассчитано на первые практические эксперименты с саунд-дизайном в Chrome или Edge под Windows 11.

Стек: Vite, React, TypeScript, Web Audio API, Web MIDI API, IndexedDB, Canvas, SVG и Workbox (`vite-plugin-pwa` 2). Серверная часть и внешние API не требуются. Версия 0.6 упаковывает завершённую 0.5 в устанавливаемую PWA, добавляет безопасные обновления, резервный перенос всей библиотеки и автоматическую публикацию через GitHub Actions. Полифония на 16 голосов, Harmonic Builder, Phrase Recorder, исправления De-click, MIDI, velocity, Pitch Bend, MIDI Learn, пять звуковых пресетов и семь уроков сохранены.

## Установка на Windows

Production-адрес: [SOUND LAB на GitHub Pages](https://harrycane1995.github.io/sound-lab/). Для обычного использования Node.js, Vite и терминал не нужны.

1. Откройте адрес в актуальном Chrome или Edge с интернетом. Дождитесь сообщения **«Готово к работе офлайн»**.
2. Нажмите **«Установить приложение»**, если браузер предложил установку, или значок установки в адресной строке. В Chrome пункт также доступен в меню ⋮ → «Трансляция, сохранение и отправка» → «Установить SOUND LAB»; в Edge — меню ⋯ → «Приложения» → «Установить этот сайт как приложение». В некоторых версиях Edge «Приложения» находятся в «Других инструментах». Название пункта зависит от языка и версии браузера. [Chrome: установка веб-приложений](https://support.google.com/chrome/answer/9658361?hl=ru), [Edge: установка и управление приложениями](https://support.microsoft.com/en-us/edge/install-manage-or-uninstall-apps-in-microsoft-edge).
3. Подтвердите установку в диалоге браузера. Через меню установленного приложения создайте ярлык или закрепите его на панели задач. SOUND LAB открывается в отдельном окне; закрывать локальный сервер безопасно.
4. Нажмите **«Подключить MIDI»** и разрешите MIDI-доступ. HTTPS-адрес отличается от localhost, поэтому разрешение нужно подтвердить заново. SysEx не запрашивается. PWA не получает дополнительных системных прав.
5. Для первой записи выберите Free → Record → сыграйте мелодию → Stop → введите имя → Save phrase. Библиотека доступна после следующего запуска, в том числе без сети.

Установку, ярлык, физический SMK-25 и прослушивание через устройство вывода нужно проверить вручную на своём компьютере. Автоматические браузерные проверки не подтверждают физическую установку Windows.

## Данные и перенос с localhost

**Музыкальные записи хранятся локально на этом устройстве, а не в GitHub.** Веб-версия GitHub Pages и установленная из неё PWA используют IndexedDB одного HTTPS-origin в одном профиле браузера. Chrome, Edge, другой профиль или устройство могут иметь отдельную библиотеку. Данные `http://127.0.0.1:5173`, `http://localhost:5173` и опубликованного адреса автоматически не объединяются.

Перед переходом откройте прежний локальный адрес и в MY PHRASES нажмите **Export library JSON**. Файл содержит все сохранённые фразы, текущий черновик и их Sound Snapshot. На опубликованном адресе выберите **Import library JSON** и подтвердите импорт. Существующие фразы сохраняются, импорт получает новые ID; повторный импорт добавляет копии. При недостатке места или превышении лимита 200 фраз вся операция отменяется. Формат версионирован, проверяются структура, размеры, ноты и снимки звука; лимит файла — 64 MiB. Для более крупной библиотеки экспортируйте фразы по одной через Export JSON (до 32 MiB каждая).

MIDI Learn и отдельный Harmonic Patch не входят в переносимый файл библиотеки. На прежнем origin они сохраняются; на новом origin назначения MIDI потребуется настроить заново. Нужный тембр можно перенести вместе с фразой в Sound Snapshot, загрузить Original Sound и при необходимости сохранить Harmonic Patch.

Service Worker хранит только ресурсы приложения. Обновление не меняет версию IndexedDB и не удаляет её или localStorage. Обычные обновления сохраняют библиотеку, Learn-привязки и Harmonic Patch. Ручная очистка данных сайта, удаление профиля браузера и некоторые варианты удаления приложения могут удалить данные: держите резервный JSON вне браузера.

## Офлайн и обновления

После первого успешного открытия Workbox кэширует HTML, JS, CSS, manifest и локальные иконки в пределах `/sound-lab/`. Шрифты берутся из системного набора, обязательных CDN нет. Синтезатор, графики, Harmonic Builder, MIDI и Phrase Recorder работают локально; пользовательские фразы остаются в IndexedDB. При офлайн-запуске открывается кэш приложения. Первичное открытие и получение новой версии требуют сети.

Проверка обновления выполняется при запуске, возвращении онлайн и к видимому окну, а также раз в час для открытого приложения. Есть ручная кнопка **«Проверить обновления»**. Новая версия ожидает подтверждения **«Обновить сейчас»**; **«Позже»** оставляет её доступной в панели приложения. Мгновенная доставка не гарантируется — она зависит от сети и жизненного цикла браузера.

Запись, отсчёт, подготовка аудио, Playing/Paused, звучащие голоса, MIDI Learn, несохранённая фраза/имя и незавершённые операции хранения/импорта/экспорта блокируют обновление. Завершите транспорт и сохраните фразу либо очистите ненужный черновик. Проверка повторяется при активации Service Worker, поэтому обновление из другого окна само не перезагружает занятую вкладку. Текущие параметры звука временно копируются в sessionStorage перед подтверждённой перезагрузкой и восстанавливаются в новом коде. Устаревшие кэши Workbox удаляются отдельно от музыкальных данных. Стратегия обновления — [prompt с подтверждением](https://vite-pwa-org.netlify.app/guide/prompt-for-update.html).

## Публикация из GitHub

Каждый push в `main` запускает `.github/workflows/deploy-pages.yml`: `npm ci` → Chromium для Linux → TypeScript → production build → полный `test:all` → официальные `upload-pages-artifact` и `deploy-pages`. При ошибке обязательного шага публикация не выполняется. Отчёты доступны в artifacts запуска Actions. Верификация имеет только `contents: read`; публикация — `pages: write` и `id-token: write`. Actions закреплены по SHA.

GitHub Pages использует источник **GitHub Actions**. Для нового форка включите его в **Settings → Pages → Build and deployment → Source → GitHub Actions**. Затем запустите workflow вручную или отправьте commit в `main`. После успешного job `deploy` адрес указан в environment `github-pages` и summary запуска. [Официальная настройка Pages workflow](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

Для отдельного домена задайте переменную сборки `SOUND_LAB_BASE_PATH=/` (по умолчанию `/sound-lab/`). Значение должно быть абсолютным путём каталога с завершающим `/`. Manifest id/start_url/scope, пути ресурсов, регистрация Service Worker и offline fallback используют одно значение. Смена домена/origin потребует переноса библиотеки через JSON.

## Разработка

Нужны Node.js 22.12+ или 24+ и npm. Откройте PowerShell:

```powershell
git clone https://github.com/HarryCane1995/sound-lab.git
cd sound-lab
npm ci
npm run dev
```

Откройте [http://127.0.0.1:5173](http://127.0.0.1:5173) в Chrome или Edge. Порт фиксирован: если он занят, остановите другой процесс на этом порту или используйте уже запущенный SOUND LAB. Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

Для сборки и локального просмотра готовой версии:

```powershell
npm run build
npm run preview
```

Production preview: [http://127.0.0.1:4173/sound-lab/](http://127.0.0.1:4173/sound-lab/). `npm run dev` по-прежнему использует корень на порту 5173, HMR и отключённый Service Worker. Не регистрируйте production worker на development-origin.

Команда `build` проверяет TypeScript и создаёт каталог `dist`.

## Возможности

- До 16 независимых голосов с формами Sine, Square, Sawtooth и Triangle. У каждой ноты свои частота, ADSR и velocity; фильтр, LFO и выход общие.
- Осциллограф и спектроанализатор получают реальные данные через `AnalyserNode`. Масштаб времени помогает различать форму при разных частотах.
- Независимые огибающие ADSR с изменяемым графиком, удержанием каждой ноты и перекрывающимися Release. Есть примеры короткого удара, мягкого пэда и органа.
- Low-Pass Filter: Cutoff, Resonance / Q и Bypass.
- LFO: Rate, Depth, включение и выбор модуляции Pitch либо Filter Cutoff.
- Виртуальная клавиатура, пять звуковых пресетов и семь компактных уроков с демонстрационными параметрами.
- Выбираемый MIDI-вход, автоматическое переподключение, монитор последних 30 сообщений, MIDI Learn для параметров и действий. Имена и CC контроллера не зашиты в код.
- Classic Oscillator и Additive Synthesis: 16 уровней гармоник, отключение без потери уровня, Solo, фазы 0°/180°, шесть отдельных Harmonic Templates, сравнение с Classic и три новых упражнения.
- Phrase Recorder: свободная/темповая запись нот и Velocity, метроном и отсчёт, Piano Roll, неразрушающая квантизация, Play/Pause/Loop, локальная библиотека, Sound Snapshot, MIDI/JSON-экспорт.

Звук начинается после действия пользователя. Начальная амплитуда снижена; фиксированное ослабление микса оставляет запас для аккордов, общий компрессор и мягкий ограничитель защищают выход. Переходы параметров сглаживаются. При потере фокуса окна или скрытии вкладки транспорт отменяется, а голоса плавно гасятся.

Движок запрашивает частоту дискретизации 48 kHz; браузер согласует её с устройством вывода. Размер FFT подбирается по фактической частоте дискретизации (обычно 16384), чтобы низкие ноты оставались различимыми. Осциллограф имеет фиксированные шкалы ×1, ×4 и ×10: они меняют только увеличение графика. При выходе за шкалу появляется отметка; выберите ×1. Анимация ограничена 30 кадрами в секунду и пропускается в скрытой вкладке.

## Управление нотами

`Play` включает отдельный голос для ручного прослушивания с частотой Frequency и velocity 127. `Stop` отпускает только этот голос с нормальным Release; MIDI, ПК и виртуальное пианино продолжают звучать. Play занимает одно из 16 мест. Для остановки всех голосов используйте Panic или Esc.

Клавиатуры работают полифонически: нажмите несколько клавиш, удерживайте и отпускайте независимо. Note Off одной ноты запускает только её Release, остальные огибающие не перезапускаются.

По умолчанию диапазон клавиатуры — C3–C4, включая верхнюю C. Переключатель начальной октавы позволяет выбрать значение от 1 до 6. Подсвечиваются все удерживаемые клавиши в видимом диапазоне; рядом показаны названия нот, число удерживаемых клавиш и реальных голосов, включая Release и Play. Ноты вне видимой октавы тоже звучат. Смена октавы отпускает локальные клавиши для безопасной смены раскладки; MIDI и Play продолжают работать.

Физические клавиши расположены как маленькая фортепианная клавиатура:

| Клавиша | A | W | S | E | D | F | T | G | Y | H | U | J | K |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Нота | C | C♯ | D | D♯ | E | F | F♯ | G | G♯ | A | A♯ | B | C следующей октавы |

Привязка использует физическое положение клавиш и работает при русской раскладке. При вводе в текстовые поля клавиши не должны запускать ноты.

Клавиши также доступны по Tab: удерживайте Space или Enter, чтобы играть. При активации через экранный диктор каждая нота удерживается до повторной активации именно этой клавиши; можно включить несколько нот. Совместимые сенсорные экраны поддерживают несколько указателей одновременно. Esc останавливает всё. Числовые значения можно печатать вручную: Enter или уход из поля подтверждает ввод и ограничивает его диапазоном, Esc возвращает значение до редактирования. Слайдеры и допустимые числовые значения меняют звук сразу.

Frequency вручную или через MIDI Learn меняет только частоту отдельного голоса Play. Удерживаемые музыкальные ноты сохраняют собственную высоту. Amplitude, Waveform, ADSR, фильтр и LFO применяются ко всему синтезатору. Загрузка пресета, урока, Reset и начало MIDI Learn быстро останавливают голоса; после этого сыграйте новые ноты. Learn-привязки сохраняются.

Идентичность каждой ноты включает источник, MIDI-канал и номер. Одинаковые ноты из разных источников звучат независимо. Повторный Note On удерживаемой ноты не создаёт дубликат. Повторное нажатие после Note Off может начать новый голос поверх затухания предыдущего.

## Полифония и Voice Stealing

Лимит 16 учитывает удерживаемые голоса, Release и Play. При заполнении сначала заменяется самый старый голос в Release; если таких нет — самый старый удерживаемый. Украденный голос получает короткий fade-out, а запоздалый Note Off его клавиши не влияет на замену. Удерживаемая украденная клавиша остаётся в реестре нажатий до отпускания, но сама больше не звучит и не перезапускается из-за повторных пакетов.

Для плавной замены допускаются до четырёх дополнительных хвостов forced fade длительностью 12 мс. Это ограниченный переход: максимум 20 физических голосов и до двух осцилляторов на голос во время crossfade формы волны, плюс один общий LFO. Счётчик «Звучит» включает эти короткие переходы, поэтому на мгновение может показывать больше 16. Если четыре переходных хвоста уже заняты, новый запуск остаётся в отменяемом ожидании до завершения ближайшего хвоста. Это добавляет небольшую задержку только к сверхбыстрой серии сверх лимита и позволяет избежать резкого обрыва звучащего осциллятора. После Release осцилляторы останавливаются, связи и таймеры очищаются.

Каждый голос проходит собственные Attack/Decay/Sustain/Release. Изменение ADSR сохраняет текущий уровень и продолжает соответствующую фазу с новыми настройками; ноты не запускаются заново. Waveform меняется коротким crossfade во всех голосах. Pitch LFO подключён к detune каждого осциллятора, Filter LFO — к общему фильтру. Анализаторы получают суммарный реальный выход.

Фиксированный коэффициент микса 1/4 оставляет запас по уровню без пересчёта громкости остальных нот при новом нажатии. Компрессор и мягкий ограничитель сохраняются; на обычных аккордах динамика velocity остаётся слышимой. Уровень одиночной ноты ниже, чем в версии 0.2.

## Harmonic Builder: услышать → увидеть → понять

Выберите **Additive Synthesis** в панели **HARMONIC BUILDER**. Исходный состав — H1 = 100%, остальные 0%: чистая синусоида. При Frequency = 220 Hz гармоники H2, H3 и H4 имеют частоты 440, 660 и 880 Hz. Нажмите Play и постепенно поднимайте их вертикальные регуляторы: тембр меняется сразу, а реальный спектр показывает новые составляющие. Редактирование гармоник автоматически включает Additive; четыре кнопки Sine/Square/Sawtooth/Triangle возвращают Classic.

H1–H8 видны сразу; H9–H16 раскрываются отдельно. **On/Off** отключает гармонику, сохраняя её уровень. **S / Solo** оставляет только выбранную включённую гармонику; повторное нажатие возвращает остальной состав. Если выбранная гармоника выключена или имеет 0%, Solo даёт тишину. В разделе **Фаза гармоник** задайте 0° или 180°: инверсия меняет форму суммы при прежних уровнях составляющих. Все регуляторы доступны с клавиатуры.

Математическая модель:

```text
signal(t) = scale × Σ A[n] × sin(2π × n × f0 × t + φ[n]), n = 1…16
scale = 1 / max(1, Σ |A[n]|)
```

В сумму входят только включённые гармоники с учётом Solo. Проценты задают относительные уровни. Если их сумма превышает 100%, общий множитель пропорционально уменьшает все составляющие; он показан как **Защита суммы**. Это гарантирует расчётную амплитуду в пределах ±1, сохраняет соотношения гармоник и делает весь нулевой набор тишиной. При добавлении гармоники H1 может стать тише: это реальное поведение защиты, а не скрытая коррекция графика. Amplitude, фиксированный запас микса 1/4, компрессор и мягкий ограничитель остаются в выходной цепи.

Звук создаётся через **PeriodicWave**, без 16 отдельных осцилляторов на каждую ноту: `real` содержит нули, `imag[n]` — нормализованные коэффициенты синусоид со знаком фазы. `disableNormalization: true` отключает неявное выравнивание браузером. Один голос использует основной carrier и кратковременный второй при смене тембра. Общий кэш на AudioContext повторно использует одинаковые PeriodicWave и хранит не более 64 форм; при dispose он очищается. Быстрые правки объединяются в последний запрошенный состав, crossfade занимает 25 мс. Удерживаемые и затухающие голоса обновляются без повторного Note On или перезапуска ADSR.

Осциллятор браузера ограничивает спектр частотой Найквиста — половиной фактической частоты дискретизации. Для высоких нот недоступные гармоники исключаются из звука; при Pitch Bend и LFO ограничение следует за высотой. Расчётный SVG показывает заданную математическую сумму, включая недоступные составляющие, и предупреждает об этом для эталонной ноты. См. [спецификацию PeriodicWave](https://webaudio.github.io/web-audio-api/#PeriodicWave) и [OscillatorNode](https://webaudio.github.io/web-audio-api/#OscillatorNode).

Три расчётные кривые показывают H1, выбранную дополнительную гармонику и сумму на одном периоде. Эталон — последняя удерживаемая нота, иначе Frequency для Play; источник и частота подписаны. Это **модель одного голоса до ADSR, фильтра, LFO и выходной обработки**. Верхние осциллограф и спектр получают **реальную общую смесь всех голосов** через AnalyserNode. При Classic расчётный график всё равно показывает сохранённый аддитивный состав для изучения.

### Шаблоны и сравнение

| Harmonic Template | Реальные коэффициенты |
| --- | --- |
| Pure Sine | Только H1 |
| Two Harmonics | H1 = 100%, H2 = 50% |
| Square Approximation | Нечётные 1/n, фазы 0° |
| Sawtooth Approximation | Все 1/n, чередование 0°/180° для возрастающей пилы |
| Triangle Approximation | Нечётные 1/n², чередование знака нечётных составляющих |
| Organ-like Tone | Несколько разных уровней; органоподобная окраска без претензии на реализм |

Шаблоны отделены от пяти исходных звуковых пресетов. При загрузке шаблона включается Additive, задаются ADSR 0.01 / 0.05 / 100% / 0.15 с, Amplitude 20%, Bypass фильтра и выключенный LFO. Изменения перечислены в статусе. Частота и удерживаемые ноты сохраняются; новые ADSR-параметры применяются к текущей фазе. Исходные пресеты и уроки возвращают Classic и сохраняют состав гармоник, а общий Reset сбрасывает также гармоники.

В **Сравните с классической волной / Compare with Classic** выберите Square, Sawtooth или Triangle. Первое сравнение загружает соответствующую аппроксимацию с нейтральными настройками. Кнопки **Сравнить: Additive / Classic** затем плавно переключают ту же удерживаемую ноту. Classic ослабляется по расчётному RMS аддитивного состава; усиление сверх обычного уровня не применяется. Выравнивание приблизительное: встроенные формы браузера, бэндлимитинг и обработка могут немного менять реальную громкость. Конечные 16 гармоник приближают форму и не совпадают с ней полностью.

Внутри Builder доступны упражнения **Рождение тембра**, **Чётные и нечётные**, **Собери прямоугольную волну** с инструкциями «Измените / Услышьте / Увидьте / Почему». Семь прежних уроков остаются в своей панели.

### Сохранение и MIDI

Режим, уровни, включение и фазы автоматически сохраняются в `sound-lab.harmonics.v1` с небольшой задержкой объединения правок. **Сохранить патч / Save Harmonic Patch** записывает отдельный пользовательский состав в `sound-lab.harmonic-patch.v1`; **Загрузить патч / Load Harmonic Patch** восстанавливает его. **Сбросить гармоники / Reset Harmonics** возвращает чистую синусоиду, сохраняя остальные параметры. Solo и Compare временные. Данные проверяются по версии, длине массивов и диапазонам; повреждённые или устаревшие данные дают понятное сообщение без падения. Недоступный localStorage позволяет продолжать текущую сессию.

Эти ключи независимы от `sound-lab.midi.v1`; сохранение патча не меняет MIDI Learn. Кнопка **M** у переключателя режима или цель **Classic / Additive · Режим синтеза** назначает переключение на пэд/CC через существующий MIDI Learn. Прежние назначения четырёх форм волн продолжают выбирать Classic. Общие коэффициенты применяются ко всем 16 голосам; абсолютные частоты гармоник следуют основной частоте каждой ноты, её Pitch Bend и Pitch LFO. Velocity, ADSR, фильтр, CC120/123, disconnect и Panic работают в обоих режимах.

## Исправление щелчков

Диагностика реального PCM обнаружила разрыв при Note Off после длительного Sustain: новая Release-рампа могла начинаться от предыдущего события автоматизации, а не от текущего уровня в текущий момент. В контрольном измерении уровень 0.7 мгновенно падал примерно до 0.194. Аналогичная ошибка затрагивала исходящий carrier при поздней смене формы волны. `cancelAndHoldAtTime()` без активной будущей автоматизации недостаточно для явной опорной точки новой рампы.

В регрессии 0.6 непрерывный PCM выявил и другой случай: при изменении активной нативной ADSR-рампы один аудиоблок повторял прежний уровень, затем возвращался к расчётной огибающей со скачком. Измерения совпадают с поведением [Blink при недоступной блокировке списка событий AudioParam](https://chromium.googlesource.com/chromium/src/+/main/third_party/blink/renderer/modules/webaudio/audio_param_handler.cc); прямое трассирование блокировки не проводилось.

ADSR теперь вычисляется по отдельным отсчётам в одном общем AudioWorklet на AudioContext. Его 20 независимых каналов соответствуют максимуму 16 голосов и четырёх коротких хвостов stealing; ChannelSplitter подаёт сигнал 0…1 нужного канала на прежний GainNode каждого голоса, intrinsic gain которого постоянно равен нулю. Процессор подготавливается один раз при включении аудио и остаётся готовым между нотами: создание Worklet и ожидание его первого блока на каждом нажатии давало дополнительную задержку. Голоса получают свободные каналы без этого ожидания. Целые планы передаются через MessagePort; номер канала, поколение его использования, instanceId и версия плана защищают от устаревших команд и подтверждений. Существующие OscillatorNode, PeriodicWave, velocity, фильтр и полифония сохранены. Запоздавшая команда соединяется коротким техническим переходом без перезапуска ADSR. Код процессора встроен в основной пакет: старая открытая вкладка может впервые запустить звук и после обновления Service Worker и удаления прежнего кэша. Для crossfade и ручного изменения частоты сохранены явные опорные точки новых рамп согласно [спецификации Web Audio](https://webaudio.github.io/web-audio-api/#dom-audioparam-linearramptovalueattime).

Сравнение непрерывных PCM-захватов с нулевым и коротким запасом планирования подтвердило разрывы во время быстрых живых переходов. В регрессии 0.6 запас 128 кадров мог исчерпаться ещё до доставки Release. В диагностическом прогоне 100 первоначальных Worklet-планов доставка достигала 512 кадров, поэтому для живых стартов и изменений огибающей задан фиксированный запас 640 кадров (около 13.33 мс при 48 kHz), включающий ещё один аудиоквант, и свежее чтение часов перед отпусканием. Значения музыкальных Attack/Release и пресеты не удлинены; будущие события фразы используют своё исходное аудиовремя. Однократное включение AudioContext и подготовка модуля перед самой первой нотой могут занять дольше. Общая задержка MIDI и физического устройства Windows не измерялась.

Живой голос сначала получает молчащий канал; короткая microtask отправляет первоначальную ADSR и запускает carrier. Note On и Note Off в одном JavaScript-вызове отменяют атаку до запуска осциллятора, затем ждут подтверждения нуля. Будущие события PhrasePlayer сразу получают план на заданное аудиовремя. В обработчиках игры аудиовызов предшествует обновлению React, чтобы отрисовка интерфейса не задерживала старт. Phrase Recorder получает исходный `performance.now()` нажатия и отпускания независимо от времени последующей обработки интерфейса.

Осцилляторы завершаются после подтверждения AudioWorklet: целый аудиоблок после окончания последнего плана действительно выдал нули. Подтверждение предыдущей версии или прежнего использования канала не разрешает освобождение нового голоса. Voice stealing использует ограниченные короткие хвосты. Dispose ждёт аудиочасы и подтверждение нуля; если аудиопоток перестал отвечать, контекст приостанавливается перед освобождением графа. Он также закрывает общий процессор, его порт и соединения. Panic в приостановленном контексте сразу освобождает голоса и обновляет фильтр, компрессор и ограничитель, очищая сохранённый в обработке аудиохвост. Сам AudioContext, анализаторы, LFO, готовый процессор огибающих, параметры и кэш гармоник сохраняются. Автоматические PCM-проверки сравнивают сигнал с реальным carrier и рассчитанной огибающей; обычные фронты Square/Sawtooth не считаются ошибкой. Отдельный отрицательный контроль с намеренным скачком проверяет чувствительность детектора. Пропуски кадров в тестовом AudioWorklet делают захват недействительным: они не трактуются как щелчок синтезатора и не засчитываются как успешное измерение.

## Phrase Recorder

Панель **PHRASE RECORDER** записывает ноты с MIDI-входа, клавиатуры ПК и виртуального пианино. Сохраняются MIDI-номер, Velocity, исходная идентичность события, источник/канал и реальные времена Note On/Off. Интервалы измеряются через монотонный `performance.now()`, а не `Date.now()`. Кнопка Play основного осциллятора, назначенные через MIDI Learn пэды и сам секвенсор в запись не попадают. CC, Pitch Bend, движения регуляторов и аудио не записываются.

### Первое сохранение

1. Подключите MIDI или используйте клавиши ПК. В Phrase Recorder оставьте **Free**, **Original**, Quantization **Off**.
2. Нажмите **Record**, сыграйте мелодию с аккордами, нажмите **Stop**. Если клавиши ещё удерживаются, их записанные интервалы завершатся временем Stop; живой звук продолжит обычную работу.
3. Посмотрите **PIANO ROLL**: горизонталь — секунды, вертикаль — ноты, ширина прямоугольника — удержание, яркость — Velocity. Масштаб ×1/×2/×4/×8 меняет только просмотр.
4. Введите **Моя первая мелодия**, оставьте **Сохранить настройки звука** и нажмите **Save phrase**. Запись появится в **MY PHRASES**.
5. После перезагрузки откройте её из библиотеки. Выберите **Original Sound** для снимка тембра либо **Current Sound** для текущего звука. Включите Loop и нажмите Play; можно играть живые ноты поверх фразы.
6. Переключите синтезатор в Additive и измените гармоники при Current Sound. Та же последовательность прозвучит новым тембром.
7. Нажмите **Export MIDI** для `.mid` либо **Export JSON** для переносимой копии с Sound Snapshot. **Import JSON** восстанавливает проверенную копию в черновик; затем Save добавляет её в библиотеку.

### Время и квантизация

**Free** сохраняет свободный ритм без обязательной сетки. **Tempo** задаёт BPM 30–300 (исходно 120), размер 4/4, необязательный метроном и один такт Count-in. Предварительный отсчёт не записывается. BPM и метроном не выравнивают сыгранные ноты автоматически. Метроном использует короткие сглаженные синусоидальные импульсы в том же AudioContext, с отдельным ограниченным пулом узлов.

Quantization **Off / 1/4 / 1/8 / 1/16 / 1/32** строит отдельную версию по исходному BPM фразы. **Original / Quantized** выбирает её для Piano Roll, Play и MIDI-экспорта. Исходные времена в памяти, IndexedDB и Phrase JSON не перезаписываются. Нота получает положительную длительность хотя бы в одну ячейку; исходные legato-перекрытия сохраняются при округлении. Очень короткие соседние ноты могут попасть в одну ячейку и звучать одновременно.

### Воспроизведение и снимок звука

PhrasePlayer планирует события по часам существующего AudioContext: JavaScript каждые 25 мс подготавливает примерно 100 мс вперёд. Осциллятор запускается нативным аудиопланированием, а огибающую и Release после Note Off исполняет AudioWorklet по аудиочасам. Голосам назначаются уникальные ID сессии, цикла и ноты, отдельный источник `sequence`. Stop/Pause фразы отменяют только её будущие события и голоса; чужие MIDI/ПК/Play продолжают работать. Panic и скрытие вкладки останавливают транспорт. Во время ожидания разрешения аудио показана «Подготовка аудио» и доступен Stop. Позднее завершение `resume()` не запускает отменённую последовательность или старое воспроизведение поверх нового дубля.

Loop создаёт новые ID для каждого цикла. Normal Release может перекрываться с началом следующего цикла, но входит в общий лимит 16 + четыре коротких хвоста stealing. При полном лимите планировщик ожидает ближайшего момента допуска вместо преждевременного отключения живой ноты за весь look-ahead. При чрезмерной перегрузке события, опоздавшие более чем на 100 мс, пропускаются с диагностикой; сохранённая запись не меняется.

Pause гасит голоса фразы и сохраняет позицию. Resume восстанавливает ещё удерживаемые в этой позиции ноты с новой атакой и остаточной длительностью. Это безопасная пауза отдельного источника, а не приостановка общего AudioContext для всех инструментов.

Sound Snapshot — глубокая копия состояния синтезатора на момент начала дубля: Classic/Additive, Waveform, гармоники/фазы, ADSR, Amplitude, Filter, LFO и ручная Frequency. При Save снимок можно исключить. **Original Sound** явно загружает его перед Play и предупреждает при звучащих live-голосах: параметры общие, поэтому их тембр тоже изменится. **Current Sound** не загружает снимок. MIDI Learn и настройки устройства в снимок не входят.

### Библиотека и резервные копии

IndexedDB `sound-lab.phrases.v1` хранит библиотеку отдельно от MIDI-настроек и Harmonic Patch. Черновик сохраняется во время игры примерно раз в секунду и после Stop, Panic, потери фокуса или отключения MIDI. Пустой дубль не заменяет предыдущую фразу. Сохранённые фразы показываются сначала новые; доступны имя, дата, длительность, число нот, исходный BPM, Play, Rename, Copy и Delete. Clear и Delete требуют подтверждения. Старое асинхронное сохранение не подменяет новый дубль.

Ограничения библиотеки: 200 фраз, до 10 минут и 10 000 нот на фразу. Phrase JSON ограничен 32 MiB, проверяется по формату/версии, размерам, диапазонам нот, времени и снимку. Повреждённые записи библиотеки пропускаются с сообщением; ошибка доступа или квоты показывается, а текущий дубль остаётся в сессии для экспорта. Данные принадлежат конкретному браузеру и локальному адресу: очистка данных сайта удаляет библиотеку. Для важных идей сохраняйте JSON-копии.

MIDI-экспорт создаёт Standard MIDI File формата 0, PPQ 480, Tempo, 4/4, Note On/Off и Velocity. Для перекрывающихся одинаковых высот используются отдельные MIDI-каналы; больше 16 таких одновременных нот даёт явную ошибку экспорта. **MIDI содержит музыкальные события, а не аудиозапись и не уникальный тембр SOUND LAB.** JSON включает исходные времена и Sound Snapshot, но не MIDI-привязки. Полное редактирование Piano Roll, overdub, аудиозапись WAV, автоматизация CC/Bend и многодорожечный микшер отсутствуют.

## Подключение M-VAVE SMK-25

1. Подключите SMK-25 к Windows по USB-кабелю с передачей данных и включите контроллер. Если он предлагает выбор режима, используйте режим USB MIDI.
2. Откройте локальный адрес в Chrome или Edge. В блоке **MIDI CONTROLLER** нажмите **Подключить MIDI** и разрешите браузеру доступ. До нажатия разрешение не запрашивается.
3. Выберите вход в списке **MIDI-вход**. Он может называться иначе, чем SMK-25: ориентируйтесь на MIDI Monitor и входящую активность.
4. Сыграйте ноту. Появятся имя, MIDI-номер, частота, канал и velocity. Кнопка подключения также подготавливает аудио без запуска ноты. Если браузер приостановил звук, нажмите Play, затем Stop и сыграйте снова.

Отдельный MIDI-сервер, сторонние драйверы и виртуальные MIDI-кабели приложению не нужны. Bluetooth MIDI работает только тогда, когда Windows уже предоставляет устройство браузеру как MIDI-вход. Подключение Bluetooth и установку драйверов SOUND LAB не выполняет. Web MIDI требует защищённого контекста: `http://127.0.0.1`, `http://localhost` или HTTPS. См. [Web MIDI API](https://developer.mozilla.org/en-US/docs/Web/API/Web_MIDI_API).

Выбранный вход сохраняется локально. После перезагрузки снова нажмите **Подключить MIDI**: при доступном входе выбор восстановится. При отключении источника его ноты останавливаются; при повторном подключении вход обнаруживается автоматически. Если порт получил новый ID, восстановление по имени возможно только при однозначном совпадении; одинаково названные известные контроллеры не объединяются.

При зависшей ноте нажмите **Panic / All Notes Off** или `Esc`. Panic очищает удержанные ноты и Pitch Bend. CC120 (All Sound Off) быстро гасит все голоса указанного источника и канала, включая Release. CC123 (All Notes Off) отпускает только его удерживаемые голоса с нормальным Release. При отключении MIDI-входа останавливаются только его голоса; ПК, виртуальные клавиши и Play продолжают работать. `Esc` во время MIDI Learn отменяет назначение; после отмены повторный `Esc` останавливает звук.

## Первый MIDI Learn

1. Выберите Sawtooth и выключите **Bypass** фильтра, чтобы изменение Cutoff было слышно.
2. Нажмите **M** рядом с **Частотой среза / Cutoff**. Поверните нужную ручку SMK-25. Первое CC-сообщение запомнит назначение и не изменит параметр.
3. Сыграйте ноту и снова поверните ручку: Cutoff и спектр будут меняться. Вспышка **MIDI** возле параметра показывает управление с контроллера.
4. Раскройте **MIDI-привязки**, выберите, например, **Пресет · Мягкий бас**, нажмите **Начать MIDI Learn**, затем нажмите и отпустите пэд. Следующее нажатие выберет пресет, не запуская музыкальную ноту. Загрузка пресета останавливает текущий звук; сыграйте новую ноту.
5. Обновите страницу, нажмите **Подключить MIDI**, проверьте ручку и пэд. Привязки сохраняются в localStorage этого браузера, включая устройство, канал, тип сообщения, номер и режим энкодера.

Все параметры имеют назначение через **M** или общий список: Frequency, Amplitude, Waveform, ADSR, Cutoff, Q, Bypass, LFO Rate/Depth/Enable/Target. В списке также есть следующая или конкретная форма волны, пять пресетов, сброс параметров и Panic. Действия принимают Note либо CC; для CC действие срабатывает при переходе из значения ниже 64 в значение 64–127. Удержанный пэд не повторяет действие. Захваченная Note используется только как действие, включая её отпускание.

Конфликт одного сигнала с другим назначением требует явного выбора **Заменить привязку** или **Отменить замену**. **M** позволяет переназначить параметр, в списке можно удалить одну привязку или все сразу. Обычный **Сброс** синтезатора сохраняет MIDI-привязки. Если браузер запрещает localStorage, текущие назначения работают в памяти, а панель показывает, что сохранить их не удалось.

### Ручки и относительные энкодеры

По умолчанию CC интерпретируется как абсолютное значение 0–127. Frequency, Cutoff и LFO Rate используют логарифмическую шкалу; остальные непрерывные параметры — линейную. Waveform выбирается из четырёх форм по диапазонам CC.

Если энкодер посылает относительные шаги, выберите режим вручную в его строке привязки. Посмотрите RAW и значения в **MIDI Monitor**:

| Режим | Шаг вверх +1 | Шаг вниз −1 | Нулевой шаг |
| --- | --- | --- | --- |
| 2’s complement | 1 | 127 | 0 |
| Binary offset | 65 | 63 | 64 |
| Sign magnitude | 1 | 65 | 0 или 64 |

Один шаг меняет нормализованное значение на 1/127, с ограничением диапазона. Режим не угадывается по пакетам: у разных прошивок он отличается. Номера CC и нот пэдов определяйте по фактическим сообщениям контроллера. CC120/123 зарезервированы для остановки нот и не назначаются через Learn.

### Velocity, Pitch Bend и Modulation

Velocity 1–127 умножает громкость ноты отдельно от Amplitude и ADSR; `Note On` с velocity 0 трактуется как `Note Off`. Клавиатура ПК, виртуальные клавиши и Play используют velocity 127.

Поддерживаются MIDI-ноты 0–127. Самая низкая нота имеет частоту 8.18 Hz (MIDI 0); её голос не ограничивается нижней границей ручного Frequency. Frequency для Play и MIDI Learn использует диапазон 20–20000 Hz.

Pitch Bend разбирается как 14-битное значение 0–16383 с центром 8192. По умолчанию диапазон ±2 полутона; в панели можно выбрать ±12. Изменение сглаживается и не запускает осциллятор или ADSR заново. Bend действует на все удерживаемые и затухающие голоса соответствующего MIDI-источника и канала, включая новые ноты. Другие каналы, ПК, виртуальное пианино и Play сохраняют высоту. Bend складывается с Pitch LFO.

Неназначенный через Learn **CC1** меняет LFO Depth. Для слышимой модуляции включите LFO; для Filter Cutoff также выключите Bypass. Другой CC можно назначить на Depth. Если CC1 назначен на другой параметр, действует это назначение. Aftertouch показывается в мониторе; управление тембром через давление пока не добавлено.

## Три первых эксперимента

1. **Высота и уровень — около 3 минут.** Загрузите «Чистая синусоида», нажмите `Play` и смените Frequency с 220 на 440 Hz: тон поднимется на октаву, пик спектра переместится вправо. Верните 220 Hz и изменяйте Amplitude: меняются уровень спектра и высота волны, а частота основного тона сохраняется.
2. **Тембр, гармоники и фильтр — около 4 минут.** При 220 Hz переключите Sine на Sawtooth: звук станет ярче, в спектре появятся дополнительные пики. Включите Low-Pass Filter, выключив Bypass, и уменьшайте Cutoff с 8000 до 500 Hz. Верхние гармоники ослабевают, звук становится приглушённым. Сравните результат с Bypass.
3. **Характер и движение — около 5 минут.** Выберите огибающую «Мягкий пэд». Удерживайте клавишу несколько секунд, затем отпустите: услышьте плавные Attack и Release. Сравните с «Коротким ударом». После этого включите LFO с Target = Pitch, чтобы услышать вибрато; переключитесь на Filter Cutoff при включённом фильтре, чтобы услышать движение тембра. Rate меняет скорость, Depth — глубину.

Панель «Что я сейчас изучаю?» предлагает более короткие упражнения и подсказки, что слушать и наблюдать. Загрузка урока или пресета меняет параметры; запускайте звук отдельно.

## Проверка аккорда на SMK-25

1. Подключите контроллер, нажмите **Подключить MIDI** и выберите его вход. Выберите «Чистая синусоида». Оставьте Play выключенным.
2. Одновременно нажмите C4, E4 и G4. Должны звучать три ноты; их имена и номера появятся в MIDI-панели, а спектр покажет три составляющих. Для видимой подсветки выберите начальную октаву C4 до игры.
3. Отпустите E4. Только она затихает по Release; C4 и G4 продолжают звучать. Счётчик удержаний станет 2, число голосов уменьшится после завершения Release.
4. Нажмите E4 с другой силой. У неё начнутся собственные Attack и velocity; остальные ноты не перезапустятся.
5. Двигайте Pitch Bend: весь аккорд одного MIDI-канала меняет высоту согласованно. Центр возвращает исходные ноты. При игре ПК или другого канала их высота не меняется от этой полосы.
6. Включите Play, затем Stop: отпускается только отдельный тон. Отпустите все клавиши — каждый голос завершит Release, счётчик станет нулевым. Проверьте Panic и отключение USB во время удержания, в том числе одновременно с клавишей ПК.
7. Выберите Two Harmonics в Harmonic Builder и снова удерживайте C4–E4–G4. Добавляйте H3/H4, меняйте Solo и фазы, затем Pitch Bend: состав общий, частоты следуют каждой ноте. Загрузите Square Approximation и сравните с Classic Square, удерживая аккорд. Проверьте переключение режима назначенным через MIDI Learn пэдом и сохранность прежних назначений.

## Границы версии 0.6

Приложение поддерживает до 16 управляемых голосов одновременно, включая Release и Play; в аддитивном составе доступны 16 гармонических синусоид с фазами 0° или 180°. У составляющих нет отдельных ADSR, негармонических частичных тонов или независимой модуляции. Фильтр и LFO общие. Теоретическая сумма и RMS-оценка сравнения не учитывают последующую обработку и бэндлимитинг.

В нём нет Electron, Tauri, нативного Windows-установщика, сэмплирования, SoundFont, реалистичных инструментов или новых эффектов, физического моделирования, драм-машины, полноценного MIDI-редактора или многодорожечной DAW, VST, экспорта WAV, облачных функций или ИИ-генерации музыки. Между перезагрузками сохраняются режим и состав гармоник, выбранный MIDI-вход, Learn-привязки, черновик и библиотека фраз со звуковыми снимками. Остальные текущие звуковые параметры возвращаются к исходным при обычном запуске; при подтверждённом обновлении PWA они переносятся через sessionStorage. RGB-подсветка пэдов не управляется.

Спектр зависит от разрешения FFT, а видимая форма сигнала — от частоты, масштаба времени, фильтра и огибающей. Пики имеют конечную ширину; это свойство анализа, а не отдельные новые ноты.
